====================================================================================================
AUTH-112 token refresh bug
====================================================================================================

Deploy is BLOCKED until the `auth-svc` fix lands. The root cause is ==probably== clock skew, but
we have not confirmed it yet. See also [[Auth service|Runbook]] and [[2026-09-28 daily log]].

== Summary =========================================================================================

Refresh tokens expire early for about 3% of users, which logs them out mid-session. It only happens
on pods that were restarted in the last hour.

NOTE: staging is shared with the payments team this week.
BLOCKER: waiting on security sign-off before touching token TTLs.

== Investigation ===================================================================================

-- What we checked ---------------------------------------------------------------------------------

- token TTL config matches across all pods
- clock drift on the affected pods
  * up to 40s behind on freshly started pods
    + NTP sync only starts after the readiness probe passes
- the outage timeline [1] lines up with the deploy at 14:02
